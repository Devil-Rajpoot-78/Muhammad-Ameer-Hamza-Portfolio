# Muhammad Ameer Hamza — Interactive 3D Creative Technology Portfolio

A premium, technical portfolio exploring the intersection of 3D art, software, engineering, robotics, mechatronics and AI-assisted creative workflows.

## Stack
- React 19 + TypeScript
- Vite
- Three.js + React Three Fiber + Drei
- Framer Motion
- Lucide

## Current build
- Cinematic responsive hero with procedural WebGL mechanical core
- 20 honest project entries with status/type labels
- Animated category filtering
- Responsive technical design system
- Reduced-motion support
- Email and WhatsApp contact shortcuts
- Proprietary project license and asset register

## Development
```bash
npm install
npm run dev
npm run build
```

## Deployment
The repository is intended for GitHub Pages. The authenticated repository is `Devil-Rajpoot-78/Muhammad-Ameer-Hamza-Portfolio.github.io`. Pages deployment is configured through GitHub Actions in `.github/workflows/deploy.yml`.
